# MyQuote 📌

MyQuote is a simple and beautiful **quote app** built with **Flutter**. It displays inspirational and motivational quotes, allowing users to read and enjoy a new quote every time they open the app.

> 🚀 This project is perfect for showcasing Flutter skills and UI implementation with a clean, modern design.

---

## 📌 Features

- ✨ **Display random quotes** on each app load  
- 🖼️ **Clean and user‑friendly UI**
- 📱 **Responsive layout** for multiple screen sizes

---

## 🧰 Built With

This app is developed using:

| Technology | Purpose |
|------------|----------|
| Flutter     | UI framework |
| Dart        | Programming language |
| Widgets     | App UI components |
